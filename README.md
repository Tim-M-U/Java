# Матрицы комплексных чисел на Java

**Лабораторная работа №1.** Выполнил: Минаев Тимофей, группа 25КНТ6.

## Кратко о работе

В лабораторной реализован класс `ComplexMatrix` — матрица, элементами которой являются комплексные числа (класс `Complex`). Класс поддерживает сложение, вычитание, умножение и деление матриц, транспонирование, вычисление определителя и обратной матрицы. Перед каждой операцией проверяется, выполнима ли она для данных размеров; если нет — выводится понятное сообщение об ошибке. Определитель и обратная матрица вычисляются методом Гаусса, поэтому программа быстро работает и с большими матрицами. Работа с программой ведётся через консольное меню: пользователь вводит матрицы (числа в привычной записи вроде `1+2i`) и выбирает нужную операцию.

## Задание

> Написать класс для работы с матрицами комплексных чисел. В классе должны быть методы, позволяющие сложить, перемножить, разделить матрицы (при возможности), транспонировать и вычислить определитель. К классу должен прилагаться консольный интерфейс, позволяющий создать матрицу и задать операцию.

## Что умеет программа

| Операция | Метод | Условие выполнения |
|----------|-------|--------------------|
| Сложение `A + B` | `add` | одинаковые размеры |
| Вычитание `A − B` | `subtract` | одинаковые размеры |
| Умножение `A · B` | `multiply` | столбцов в `A` столько же, сколько строк в `B` |
| Деление `A / B = A · B⁻¹` | `divide` | `B` квадратная и невырожденная, умножение `A · B⁻¹` возможно |
| Транспонирование `Aᵀ` | `transpose` | всегда |
| Определитель `det A` | `determinant` | матрица квадратная |
| Обратная матрица `A⁻¹` | `inverse` | матрица квадратная и `det A ≠ 0` |

Если операция невозможна, программа не падает, а пишет причину, например:
`Ошибка: умножение невозможно: у A 3 столбц(а/ов), а у B 2 строк(и)`.

### `Complex`

Неизменяемый класс комплексного числа `re + im·i`.

- `plus`, `minus`, `times`, `dividedBy`, `negate`, `abs`;
- `Complex.parse("1-2.5i")` — разбор числа из строки (поддерживаются `3`, `-2.5`, `i`, `-4i`, `1+2i`, `0.5-1.5i`, допускается запятая вместо точки);
- `toString()` печатает число в привычном виде: `3`, `-i`, `2-3i`, `0.5+1.25i`. Значения, близкие к нулю (`|x| < 1e-10`), выводятся как `0`.

### `ComplexMatrix`

- хранит элементы в массиве `Complex[height][width]`;
- все операции возвращают **новую** матрицу, исходные не изменяются;
- **определитель** считается методом Гаусса (приведение к верхнетреугольному виду с выбором главного элемента по столбцу) — сложность `O(n³)`;
- **обратная матрица** находится методом Гаусса–Жордана (`[A | E] → [E | A⁻¹]`);
- `toString()` печатает матрицу с выравниванием по столбцам.

### `MatrixCalculator`

Консольное меню: ввод матриц `A` и `B`, выбор операции, вывод результата. Некорректный ввод (не число, неверное количество элементов в строке, отрицательный размер) не прерывает программу — предлагается ввести заново.

## Сборка и запуск

Нужен JDK 14 или новее (используются `switch`-выражения).

```bash
javac -encoding UTF-8 -d out src/*.java
java -cp out MatrixCalculator
```

Можно также открыть папку в IntelliJ IDEA, пометить `src` как *Sources Root* и запустить `MatrixCalculator`.

> Если в консоли Windows вместо русского текста видны «кракозябры», выполните `chcp 65001` перед запуском.

## Как пользоваться

1. При запуске программа просит ввести матрицу `A`: число строк, число столбцов, а затем сами строки — элементы через пробел, через `, ` (запятая с пробелом) или через `;`. Например: `3, -1.2, i` или `3 -1.2 i`.
2. Дальше появляется меню:

```
----------------- Меню -----------------
 1. Ввести матрицу A
 2. Ввести матрицу B
 3. Показать матрицы
 4. A + B
 5. A - B
 6. A * B
 7. A / B   (= A * B^-1)
 8. Транспонировать
 9. Определитель
10. Обратная матрица
 0. Выход
----------------------------------------
```

Для операций с двумя матрицами, если `B` ещё не задана, программа сама попросит её ввести. Для транспонирования, определителя и обратной матрицы можно выбрать, к какой матрице (`A` или `B`) применить операцию.

### Пример сеанса

```
--- Ввод матрицы A ---

Количество столбцов: 2
Введите 2 строк(и) по 2 элемент(а/ов) через пробел, ", " или ";":

строка 2: i 4
Матрица A (2x2):

| i      4 |

Ваш выбор: 2

--- Ввод матрицы B ---
Количество строк: 2
Количество столбцов: 2
строка 1: 2-i 0
строка 2: 1 1+i
Матрица B (2x2):
| 2-i   0   |
| 1     1+i |

Ваш выбор: 6
A * B (2x2):
| 7+3i   3+3i |
| 5+2i   4+4i |

Ваш выбор: 7
A / B (2x2):
| -0.9+1.3i   1.5-1.5i |
| -1.4+0.8i   2-2i     |

Ваш выбор: 9
Для какой матрицы (A/B)? B
det(B) = 3+i
```

## Ограничения

- Числа хранятся в `double`, поэтому возможны небольшие погрешности округления; при выводе дробная часть округляется до 4 знаков.
- Матрица считается вырожденной, если в процессе исключения ведущий элемент по модулю меньше `1e-10`.
